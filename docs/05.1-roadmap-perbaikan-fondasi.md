## 3. Ringkasan per item

### #0 — CI baseline · ✅

**Tujuan:** gate CI statis + suite test terpisah. **Hasil:** `pytest` exit 0 dengan/tanpa
`frappe`; baseline `ruff` 746 error; 3 test statis + 4 test murni. **Test:**
`test_import_smoke.py`, `test_app_structure.py` (xfail sampai #2), `test_repo_hygiene.py`
(xfail sampai #3). **Catatan:** `test_doctype_count_is_13` dan
`test_no_db_commit_in_test_files` sudah xpass.

### #1 — Security darurat · 🟡

**Tujuan:** tutup lubang yang bisa dieksploitasi sekarang (`N1, N2, S1–S5, S11, N4, N5/S12`).

**Sudah:** auth `/api/chatbot/*`; ownership `conversationId` di `/stream`; `allow_guest`
draft dicabut; `Pending Action Draft` jadi file JSON; parse-pdf wajib sesi + batas 5 MB;
fallback tenant dihapus; path mesin dibersihkan; register anti-enumerasi; payment tidak
hardcode `ACTIVE`; guard koneksi DB + default `root` dihapus.

**S3 selesai:** helper `resolve_session_connection(sess)` (user-first, legacy lewat
`AIOS Tenant.email`, tanpa `companyId` sebagai bukti) dipakai 7 endpoint
connection/mapping; `/api/mapping/validate` memvalidasi input, mengotorisasi semua
entry sebelum menulis, dan meng-update mapping milik entry; fallback `/api/mapping`
kini 401/404. **Test runtime:** `test_mapping_validate_ownership.py` (15 test),
`test_authz_dispatcher.py`, `test_connection_user.py`; mutation M1–M6 merah.

**Residual transisi (#4a):**
1. Legacy tenant dengan >1 user terblokir aturan ketat `AIOS Tenant.email == sess.user`;
   backfill `AIOS DB Connection.user` saat #4a.
2. `companyId` masih dipakai di `/stream` (`dispatcher.py:1048`) dan dikembalikan
   `/api/auth/me`; `_legacy_company_id` + field `tenant` transisi dihapus #4a.
3. Permission read `AIOS Mapping`/`AIOS Mapping Entry`/`AIOS Schema Snapshot` masih #4a.

**Acceptance:** C1–C11 terverifikasi (15 test mapping + 8 authz + 5 connection); mutation
M1–M6 merah; regression-before-fix C1/C3/C4/C8 merah di HEAD. **Risiko:** aturan legacy
ketat bisa memblokir tenant lama multi-user sampai backfill #4a.

### C — Ownership per `User` (Tahap C) · ✅

**Tujuan:** `user -> Link(User)` + hook izin + `Pending Action Draft`, tanpa tenant baru.

**Hasil:** `AIOS Conversation` & `AIOS Agent State` lepas `tenant`; `AIOS DB Connection`
dapat `user` dengan `tenant` sebagai kolom transisi; `Pending Action Draft` file JSON
(`user`, `rejection_reason`); `permission_query_conditions` + `has_permission` aktif;
`draft_manager` cek kepemilikan; draft baru terikat sesi via `before_insert`; DocPerm
dasar `AIOS Client`/`AIOS Admin` via `after_install`/`after_migrate`.

**Acceptance:** Alpha tidak bisa `get_doc`/`get_list`/`save`/`delete` resource Beta; baris
`user=NULL` tidak terlihat `AIOS Client`; resource sendiri lolos; tanpa sesi 401;
`Administrator`/`AIOS Admin` penuh; draft Beta tidak bisa di-approve Alpha.

**Test:** 8 isolasi + 21 P0/P1 + 33 P2/P3; mutation check 5/5 merah saat kode dirusak.
**Deviasi tercatat:** `AIOS DB Connection` sementara punya `tenant` + `user`.

## 5. Test & verifikasi

**Aturan:** tidak ada item dianggap selesai tanpa test yang membuktikan klaimnya.

- **Statis (CI tanpa `frappe`):** `cd apps/aios_v1 && pytest -q`. Hanya file di allowlist
  `aios_v1/tests/conftest.py` yang dikumpulkan.
- **Integrasi (butuh site):**
  `cd ~/mybench-v16 && bench --site aios-v16.localhost run-tests --app aios_v1 --module <modul>`.
- **Lokasi test:** semua `test_*.py` baru di paket dalam `aios_v1/aios_v1/tests/` (bukan
  root app), karena `bench run-tests` hanya me-walk paket dalam.
- **Mutation check:** untuk klaim keamanan, rusak sengaja kode → test harus merah → revert.
  Sudah dilakukan untuk 5 titik Tahap C (semua merah).
- **Regression-before-fix:** bila tidak feasible (mis. test lama di-skip dan skemanya
  usang), tulis alasannya di laporan; jangan klaim ✅.
