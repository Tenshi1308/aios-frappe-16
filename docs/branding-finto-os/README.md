# Branding Finto OS / Fino

Aset branding dari Pak Oscar (16 Nov 2026) untuk AIOS — logo, maskot Fino, palet
(navy #0B1F3B, biru #0E63FF, cyan #00D4C8, lime #A7F432, violet #8B5CF6, terang #F3F7FB).

- `logo/` — varian logo Finto OS (PNG/SVG).
- `mascot/` — maskot Fino (fino-celebrate, fino-welcome, finto-analyze-data,
  finto-automation, finto-hero-front, finto-flat-logo, dll.).
- `demo-booting-finto-os.mp4` — video booting 5,4 detik (CATATAN: ini boot produk
  SPI sekolah, bukan AIOS — log-nya modul Admisi/Akademik/Keuangan SPP/Penggajian).
- `referensi-asli/` — dokumen + snapshot kode MENTAH dari project SPI Pak Oscar
  (Finto Edu), BUKAN spec AIOS. Referensi saja, jangan disalin mentah-mentah:
  `referensi UI finto-os/` berisi 01_RENCANA_TEKNIS_FINTO_OS.md,
  02_SPESIFIKASI_TAMPILAN_FINTO_OS.md, 03_INVENTARIS_FILE.md,
  04_SELISIH_FRONTEND_FINTO_EDU_VS_SPI.md, README.md, dan `kode-snapshot/`
  (frontend Vue spi_fintoedu). Menu/fitur SPI (PPDB, Murid, Kelas, SPP, Honor)
  TIDAK berlaku untuk AIOS.
